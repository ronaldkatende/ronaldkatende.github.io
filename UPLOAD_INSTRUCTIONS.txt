4. Make sure index.html is visible at the REPOSITORY ROOT after uploading. Commit changes.
5. Settings > Pages: Source = Deploy from a branch; branch = main; folder = /(root), or use the specific existing GitHub Pages workflow if configured.
6. Actions tab: verify Pages build/deploy succeeds. Then open https://ronaldkatende.github.io/ and check Publications and CV.

IMPORTANT: If site is configured to publish from /docs rather than /(root), put all files INSIDE docs/ instead, or change Pages settings to /(root).
