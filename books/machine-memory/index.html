Machine Memory

Mathematics, Algorithms, Architectures and Reliable Computation

Ronald Katende · Seven chapters and two appendices · 308-page manuscript

A machine receives information, keeps a state, and uses that state to answer a later question. What must survive between those moments? When can a smaller representation do the same work, and when does a change in memory destroy something a future computation needs?

This book examines those questions across algorithms, numerical analysis, dynamical systems and machine learning. It starts with simple stored summaries and develops the mathematics needed to judge how much information must be retained. Later chapters investigate changes to internal representations and the costs of implementing and verifying them.

How to use this book

Readers can begin with the short examples, work through the mathematical derivations, and then run the associated programs where available. The manuscript distinguishes controlled calculations from measured-data investigations. Some recorded results and external datasets still require independent reproduction before they can be considered independently verified.

This is a working academic manuscript, not a claim of final editorial or independent scholarly review. The chapter titles and page count above refer to the complete 308-page edition available in the author's files.
