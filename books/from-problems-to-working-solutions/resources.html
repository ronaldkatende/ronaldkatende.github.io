Laboratories and reproducibility

The companion notebooks run with Python, NumPy, pandas, SciPy, Matplotlib and scikit-learn where required. They use labelled illustrative data unless an exercise states otherwise. The underlying mathematical claims should be checked independently of the scripts.

You can use the notebooks in JupyterLab without Quarto, or use the programs directly from the code/ directory. Each laboratory starts from the decisions and modelling assumptions of its chapter. Output files from a script are not observations from a real health facility, water utility or public institution.

When downloading data from an outside source, record its URL, date, licence, time coverage and collection method. Keep raw records separate from transformations.

For Windows users, after extracting the full source archive, open Anaconda Prompt in the project directory and run jupyter lab. Open the notebooks/ folder. To build the website from Quarto, run quarto render --to html.
